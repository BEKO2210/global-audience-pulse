## Anforderungen

1. **Gewählte Zeit (Zeitmaschine/Scrub)** als deutlicher Cursor über alle Zeilen: 2–3 px in `--ink` (nicht Orange, damit er sich von den Akzent-Zellen abhebt), mit **Beschriftung oben** als kleines Etikett („Sa 16:15“, aus dem gewählten Zeitpunkt, Nutzer-Zeitzone) und einem dezenten Halo (`--paper` 1 px beidseitig), damit er auf jeder Zellfarbe sichtbar bleibt. Position minutengenau innerhalb der Stundenspalte.
2. **„Jetzt“** bleibt separat erkennbar (eigene, schwächere Markierung + Beschriftung „jetzt“); sind Jetzt und gewählte Zeit gleich, nur eine Markierung.
3. Die Zellen der gewählten Spalte bekommen eine feine Umrandung, die Zeilen-/Spaltenköpfe der gewählten Stunde werden hervorgehoben (Fettschrift).
4. **Städtenamen nie abschneiden** (Spaltenbreite für Labels so wählen, dass „Los Angeles“/„São Paulo“ auf 360 px passen, ggf. Flagge kleiner).
5. Bewegung beim Scrubben weich (≤ 150 ms, `prefers-reduced-motion` = sofort).
6. Kontrast: Cursor ≥ 3:1 gegen alle 5 Zellstufen in hell und dunkel (WCAG 1.4.11).
7. E2E: Cursor sichtbar, Etikett zeigt die gewählte Zeit nach Scrub, Etikett „jetzt“ vorhanden, keine abgeschnittenen Städtenamen (scrollWidth ≤ clientWidth der Label-Zellen), axe wcag22aa ohne serious/critical.
