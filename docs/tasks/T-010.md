# T-010 – Warum ist eine Region gerade auffällig? (Trendthemen)

**Zaun:** Nur `scripts/analysis/*` und neue Tests unter `scripts/analysis/`. Keine Git-Zustandsänderungen. Bericht in `REPORT-T-010.md`. Der Job läuft auf pop-os mit Ollama (localhost:11434) – Agenten ohne localhost-Zugriff (Codex-Sandbox) bauen Code + Unit-Tests mit Mock-Antworten; Claude macht den Echtlauf.

## Ziel

Wenn `liveSignale[].abweichungProzent` einer Region betragsmäßig > 15 % ist: die Wikimedia-Top-Artikel des Vortags
dieser Sprache laden (`https://wikimedia.org/api/rest_v1/metrics/pageviews/top/{project}/all-access/{YYYY}/{MM}/{DD}`,
User-Agent wie in `signals.ts`), Haupt-/Spezialseiten herausfiltern (Main_Page, Spezial:/Special:, Wikipedia:, Datei: …),
die Top 8 Titel als Fakten `trendThemen` an den Bericht geben. Das lokale Modell fasst sie in **einem neutralen Satz**
zusammen („Brasilien heute aktiver – meistgelesen: Politik rund um die Präsidentschaft“). Keine Spekulation über
Personen, keine Wertungen; Prüfer (qwen3.5:9b) muss den Satz gegen die Titel prüfen.

## Abnahme

- Fakten enthalten `trendThemen` nur für auffällige Regionen; ohne Auffälligkeit kein Abruf.
- Fehler/Timeouts der API brechen den Bericht nicht ab.
- Unit-Tests für Filter und Auswahl (Fixture mit echtem API-Format).
